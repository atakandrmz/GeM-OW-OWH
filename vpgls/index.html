v_pgls: PGLS probability as the weight of DBoW2 loop edges

← back to the dashboard (group v_pgls in the configuration list; the 2×2 button there opens the same table for any configuration)

Acceptance is the VINS-Mono default (DBoW2 0.05 / 0.015, BRIEF + PnP, legacy yaw and translation gate). The online PGLS probability P is used only as the weight of the accepted loop edge in the 4-DoF pose graph; there is no P threshold. Weight 1 is VINS as it is. “top-1” = one edge per keyframe, “top-4” = up to four. Counts are means over the repetitions, summed over the 7 sequences. True = ground-truth pgls ≥ 0.5. Ground truth: original pgls (results/).
