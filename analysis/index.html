Geometry-gate analyses (v2 runs, offline)

Read-only analyses of the finished v2 grid. Back to the dashboard.

  • gate_stats.txt - where candidates die: proposed / verified / rejected by BRIEF, PnP, LighterGlue-PnP, pose gate.
  • gate_whatif.txt (csv) - what looser pose gates (45/30, 60/50, 90/50, 180/100) would have added: true vs false loops.
  • gate_pgls.txt (csv) - PGLS-style gate (P ≥ pmin) vs the current gate, with pose error against ground truth.
  • check_v2.txt - completeness and sanity check of the grid.
